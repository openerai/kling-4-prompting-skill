# Kling 4 공식 사양과 경계

근거: [Kling 4.0 User Guide](https://kling.ai/quickstart/kling-4-model-user-guide),
문서 표기 2026-10-14, 확인 2026-10-18 (Asia/Seoul).
수치는 웹 가이드 기준이다. 실행 시 실제 UI/연결 도구와 다르면 그 경로의 현재
제약을 따르고 차이를 알리라. API 모델 ID나 파라미터로 그대로 전사하지 말라.

## 사양표

| 항목 | 가이드에서 확인한 범위 |
|---|---|
| 일반 4.0 생성 | 3–30초, 1초 단위; 기본 10초 |
| 해상도 | 720p / 1080p / 4K |
| 비율 | 21:9 / 16:9 / 1:1 / 9:16; Omni Auto 기본 |
| 텍스트 | 최대 8,000 **토큰**, 글자 수가 아님 |
| Omni 전체 | 이미지·영상·음성 프로필·요소 합계 15개 이하 |
| 이미지 | 최대 10개; 각 30MB 이하; 입력 비율 2:5–5:2 |
| 영상 참조 | 최대 5개; 각 3–30초·300MB 이하; 합계 30초 이하; 비율 2:5–5:2 |
| 음성 프로필 | 최대 3개; 생성용 오디오 5–30초·50MB 이하 |
| 요소 | 최대 7개; 이 중 비디오 요소 최대 3개; 생성용 원본 3–8초 |
| 공유 영상 할당량 | 참조 영상 + 편집 영상 + 비디오 요소 합계 5개·30초 이하 |
| 편집 영상 | 최대 5클립, 그중 주 원본 1개; 공유 영상 한도 내에서 사용 |
| Keyframes | 이미지 최대 10개, 이미지당 30MB 이하; 3–30초; 첫/끝/중간 프레임 |
| Keyframes 입력 | 이미지 전용; 별도의 참조 자산 업로드 미지원; 비율은 첫 키프레임 기준 |
| Flash | 최대 20초·720p; 첫+끝 프레임 및 다중 키프레임 미지원 |
| 오디오 출력 | 2채널 스테레오; 한국어 포함 다국어 발화 지원 |
| 오디오 입력 | 음성 프로필 참조만; BGM·효과음 파일 입력 미지원 |
| 자동 기능 | 오디오-비주얼 동기화와 Smart Storyboard 기본 활성, 별도 토글 없음 |
| 문자 | 다국어·이모지·로고 렌더링 지원; 결과의 정확성 보장은 아님 |

각 유형 한도와 전체 한도를 **동시에** 충족하라. 예: 이미지 10 + 영상 5 + 음성
1개는 유형별로 맞더라도 합계 16개라 초과다. 영상 4 + 비디오 요소 2는 공유
영상 수가 6개라 초과다. 영상 한 개를 동작과 카메라에 함께 참조하는 것은 실제
슬롯이 하나인 경우 한 번만 센다. 서로 다른 업로드 슬롯을 임의로 중복 제거하지 말라.

## 공식 문서 안의 충돌을 처리하는 규칙

| 충돌/불확실성 | 채택하는 처리 |
|---|---|
| 10-bit HDR가 사양표에는 있지만 개요에 coming soon 표기 | 1080p/4K 대상 출시 예고로 취급; 계정 UI/도구에서 확인 전 사용 가능으로 확정하지 않기 |
| 최대 2분 연장 | coming soon; 현재 일반 기능으로 제안하지 않기 |
| Keyframes 예시에 @Video가 등장 | 입력 표·FAQ의 이미지 전용/진입점 결합 불가를 우선; 혼합 예제를 별도 Keyframes 입력 근거로 쓰지 않기 |
| 네거티브 최소화 원칙과 긴 금지 목록 예시 | 원칙을 기본으로 사용; 원테이크·변경 범위·스타일 혼합 같은 작업상 필수 배제만 짧게 추가 |
| 명확한 단문 권장과 8,000토큰 상한 | 상한은 목표 길이가 아님; 결과에 영향을 주는 정보만 추가 |
| 한국어 지원과 다양한 중국/영어 억양 예시 | 한국 사투리별 품질/공식 지원 범위를 추정하지 않기 |
| 정밀 프레임/문자/원본 오디오 보존 지시 | 요청·능력 설명과 실제 결과 보장을 구분; 출력 관찰 없이 성공 확정 금지 |

근거 위치: §1.1–1.2, §2.1–2.2, §3.1 입력 표·편집·오디오·스타일,
§3.2 입력 표, FAQ의 버전·공유 할당량·오디오·토글 항목.

사양을 갱신할 때 공식 문서를 다시 열어 문서 날짜와 실제 기능 상태를 확인하라.
새 문서나 계정 UI를 보지 않고 '이제 HDR/확장이 지원된다'고 자동 갱신하지 말라.
